# Study Bot

A Discord study bot built with Python.

I built this project to create a Discord bot that can help with studying, revision, and other educational tasks. It includes AI assistance, study commands, a SQL database, and other Discord features.

## Status

**Alpha**

This project is not actively maintained at the moment, so some features may contain bugs or may not work as expected.

## Features

* AI study assistance
* Study and revision commands
* Discord slash commands
* SQL / SQLite database
* Modular cog system
* OpenRouter AI integration
* Data storage and retrieval

## Built With

* Python
* Discord.py
* SQL / SQLite
* OpenRouter API
* python-dotenv
* Flask

## Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd discord-bot
```

### 2. Install the requirements

```bash
pip install -r requirements.txt
```

### 3. Create a `.env` file

Add your Discord bot token and OpenRouter API key:

```env
TOKEN=your_discord_bot_token
OPENROUTER_API_KEY=your_api_key
```

### 4. Run the bot

```bash
python main.py
```
